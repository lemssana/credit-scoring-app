# Техническая документация проекта: Credit Risk Scoring System

## 1. Архитектура и описание проекта
Проект представляет собой автоматизированную систему оценки кредитного риска (скоринга) физических лиц. Решение включает в себя модель машинного обучения для классификации заемщиков на надежных и потенциальных неплательщиков (дефолт), а также интерактивный веб-интерфейс для демонстрации работы алгоритма в реальном времени.

## 2. Этапы реализации
1. **Предобработка данных (Data Preprocessing):**
   - Загрузка и очистка датасета (обработка пропусков, кодирование категориальных признаков методом One-Hot Encoding).
2. **Обучение модели (Model Training):**
   - Использование алгоритма **Random Forest Classifier** (`n_estimators=100`).
   - Разделение выборки на обучающую и тестовую в соотношении 80/20.
3. **Оценка качества (Evaluation):**
   - Достигнут высокий уровень метрики **ROC-AUC: 0.9339**.
4. **Интерфейс и деплой (Deployment):**
   - Реализация веб-приложения с помощью фреймворка **Streamlit**.
   - Сериализация модели с использованием библиотеки **Joblib**.

## 3. Анализ признаков (Feature Importance)
На основе анализа обученной модели ключевыми факторами, влияющими на решение о выдаче кредита, являются:
1. `loan_percent_income` — отношение суммы кредита к доходу заемщика.
2. `person_income` — годовой доход клиента.
3. `loan_int_rate` — процентная ставка по кредиту.
